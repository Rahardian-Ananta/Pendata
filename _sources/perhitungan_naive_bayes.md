## LANGKAH 4 — Hitung Likelihood dengan Distribusi Gaussian

$$P(x \mid c) = \frac{1}{\sqrt{2\pi\sigma^2}} \cdot e^{-\dfrac{(x-\mu)^2}{2\sigma^2}}$$


### 🔴 KELAS 0 (Gagal)

**▸ P(jam_belajar = 0.6667 | Gagal)**

$$x - \mu = 0.6667 - 0.1167 = 0.5500$$
$$(x-\mu)^2 = (0.5500)^2 = 0.3025$$
$$\text{eksponen} = -\frac{0.3025}{2 \times 0.011389} = -\frac{0.3025}{0.022778} = -13.2803$$
$$e^{-13.2803} = 0.000002$$
$$\frac{1}{\sqrt{2\pi \times 0.011389}} = \frac{1}{\sqrt{0.071559}} = \frac{1}{0.267506} = 3.7382$$
$$\boxed{P = 3.7382 \times 0.000002 = 0.000006}$$

**▸ P(kehadiran = 0.6757 | Gagal)**

$$x - \mu = 0.6757 - 0.2000 = 0.4757$$
$$(x-\mu)^2 = (0.4757)^2 = 0.2263$$
$$\text{eksponen} = -\frac{0.2263}{2 \times 0.015807} = -\frac{0.2263}{0.031614} = -7.1572$$
$$e^{-7.1572} = 0.000779$$
$$\frac{1}{\sqrt{2\pi \times 0.015807}} = \frac{1}{0.315148} = 3.1731$$
$$\boxed{P = 3.1731 \times 0.000779 = 0.002473}$$

**▸ P(nilai_tugas = 0.6667 | Gagal)**

$$x - \mu = 0.6667 - 0.1800 = 0.4867$$
$$(x-\mu)^2 = (0.4867)^2 = 0.2368$$
$$\text{eksponen} = -\frac{0.2368}{2 \times 0.007748} = -\frac{0.2368}{0.015496} = -15.2842$$
$$e^{-15.2842} = 0.000000$$
$$\frac{1}{\sqrt{2\pi \times 0.007748}} = \frac{1}{0.220640} = 4.5323$$
$$\boxed{P = 4.5323 \times 0.000000 = 0.000001}$$

**▸ Posterior Kelas 0:**
$$\text{Posterior}_0 = 0.000006 \times 0.002473 \times 0.000001 \times 0.40 \approx \mathbf{0.000000}$$
