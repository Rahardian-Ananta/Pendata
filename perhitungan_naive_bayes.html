LANGKAH 3 — Prior#

\[P(\text{Gagal}) = \frac{10}{25} = 0.40 \qquad P(\text{Lulus}) = \frac{15}{25} = 0.60\]

LANGKAH 4 — Hitung Likelihood dengan Distribusi Gaussian#

\[P(x \mid c) = \frac{1}{\sqrt{2\pi\sigma^2}} \cdot e^{-\dfrac{(x-\mu)^2}{2\sigma^2}}\]

🔴 KELAS 0 (Gagal)#

▸ P(jam_belajar = 0.6667 | Gagal)

\[x - \mu = 0.6667 - 0.1167 = 0.5500\]
\[(x-\mu)^2 = (0.5500)^2 = 0.3025\]
\[\text{eksponen} = -\frac{0.3025}{2 \times 0.011389} = -\frac{0.3025}{0.022778} = -13.2803\]
\[e^{-13.2803} = 0.000002\]
\[\frac{1}{\sqrt{2\pi \times 0.011389}} = \frac{1}{\sqrt{0.071559}} = \frac{1}{0.267506} = 3.7382\]
\[\boxed{P = 3.7382 \times 0.000002 = 0.000006}\]

▸ P(kehadiran = 0.6757 | Gagal)

\[x - \mu = 0.6757 - 0.2000 = 0.4757\]
\[(x-\mu)^2 = (0.4757)^2 = 0.2263\]
\[\text{eksponen} = -\frac{0.2263}{2 \times 0.015807} = -\frac{0.2263}{0.031614} = -7.1572\]
\[e^{-7.1572} = 0.000779\]
\[\frac{1}{\sqrt{2\pi \times 0.015807}} = \frac{1}{0.315148} = 3.1731\]
\[\boxed{P = 3.1731 \times 0.000779 = 0.002473}\]

▸ P(nilai_tugas = 0.6667 | Gagal)

\[x - \mu = 0.6667 - 0.1800 = 0.4867\]
\[(x-\mu)^2 = (0.4867)^2 = 0.2368\]
\[\text{eksponen} = -\frac{0.2368}{2 \times 0.007748} = -\frac{0.2368}{0.015496} = -15.2842\]
\[e^{-15.2842} = 0.000000\]
\[\frac{1}{\sqrt{2\pi \times 0.007748}} = \frac{1}{0.220640} = 4.5323\]
\[\boxed{P = 4.5323 \times 0.000000 = 0.000001}\]

▸ Posterior Kelas 0: $\(\text{Posterior}_0 = 0.000006 \times 0.002473 \times 0.000001 \times 0.40 \approx \mathbf{0.000000}\)$

🟢 KELAS 1 (Lulus)#

▸ P(jam_belajar = 0.6667 | Lulus)

\[x - \mu = 0.6667 - 0.6444 = 0.0222\]
\[(x-\mu)^2 = (0.0222)^2 = 0.000494\]
\[\text{eksponen} = -\frac{0.000494}{2 \times 0.047654} = -\frac{0.000494}{0.095308} = -0.005182\]
\[e^{-0.005182} = 0.994832\]
\[\frac{1}{\sqrt{2\pi \times 0.047654}} = \frac{1}{0.547192} = 1.8275\]
\[\boxed{P = 1.8275 \times 0.994832 = 1.8181}\]

▸ P(kehadiran = 0.6757 | Lulus)

\[x - \mu = 0.6757 - 0.7009 = -0.0252\]
\[(x-\mu)^2 = (-0.0252)^2 = 0.000636\]
\[\text{eksponen} = -\frac{0.000636}{2 \times 0.041633} = -\frac{0.000636}{0.083266} = -0.007642\]
\[e^{-0.007642} = 0.992387\]
\[\frac{1}{\sqrt{2\pi \times 0.041633}} = \frac{1}{0.511457} = 1.9552\]
\[\boxed{P = 1.9552 \times 0.992387 = 1.9403}\]

▸ P(nilai_tugas = 0.6667 | Lulus)

\[x - \mu = 0.6667 - 0.7244 = -0.0578\]
\[(x-\mu)^2 = (-0.0578)^2 = 0.003338\]
\[\text{eksponen} = -\frac{0.003338}{2 \times 0.036398} = -\frac{0.003338}{0.072796} = -0.045857\]
\[e^{-0.045857} = 0.955178\]
\[\frac{1}{\sqrt{2\pi \times 0.036398}} = \frac{1}{0.478221} = 2.0911\]
\[\boxed{P = 2.0911 \times 0.955178 = 1.9974}\]

▸ Posterior Kelas 1: $\(\text{Posterior}_1 = 1.8181 \times 1.9403 \times 1.9974 \times 0.60 = \mathbf{4.2276}\)$
